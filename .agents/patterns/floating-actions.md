# Floating actions and filter sheets

> **What:** page-level floating buttons (Add Task, Add Groceries, Scan Item, recipe/inventory Search, Sort, Filter) and the sort/filter sheets they open. **Read when:** a page has a web `DashboardFloatingAction` or a sort/filter modal.

- One bar per page: `.floatingActionBar([FloatingAction], search: FloatingSearch?)` on the page's scroll view. It uses `safeAreaBar(edge: .bottom, alignment: .trailing)` with a hard bottom scroll edge effect on iOS 26+ (`safeAreaInset` before), so the last row scrolls clear of the bar and rows under it are covered rather than showing through; never overlay it by hand.
- Direction G (mockups n5 Chores, n6 Recipes and All Food): the bar is the page's bottom toolbar on the navigation layer.
  - `FloatingAction(showsTitle: true)` is a labeled 52 pt capsule. The page's one primary action ("Add Task", "Add Groceries") is filled with G's `#0071E3` (`isProminent`, the default); a secondary labeled action ("Scan Item" on an empty pantry) passes `isProminent: false` and sits on glass.
  - `showsTitle: false` is a 52 pt glass circle (Sort, Filter, icon-only Scan) that keeps its title as the VoiceOver label. `isActive` (a sort or filter is applied) fills it `#F2F2F7` under a black glyph and adds `.isSelected`.
  - Search (`FloatingSearch`) is a glass capsule that fills the bar's leading space with the magnifier and the prompt (or the typed query); at accessibility sizes it is a magnifier circle. Tapping it opens the field, which takes the bar's width and hides the other actions (web recipe/inventory search). Close clears the text and collapses.
  - Glass is `navigationGlass(in:)` (Liquid Glass on iOS 26, thin material before). Contrast is in `FloatingActionBarTests.tintsKeepTextReadable`; record any other fill the same way. (Before G the bar used the web's chore blue and active brown, darkened to (0,110,145) and (135,95,55).)
- Sort/filter modals use `FilterSheet(title:canApply:canReset:onApply:onReset:)`, an edit sheet in G's form: `SheetCancelItem` (circle x, leading) drops the draft, `SheetConfirmItem("Apply")` (filled check, trailing; `HassDesign/SheetEditToolbar.swift`) commits it and closes, disabled until the draft changes. "Reset to Defaults" is a list row in the action tint that restores defaults in the draft only, shown only while `canReset` (a disabled row fails the contrast audit). Titled sections are `FilterSection("…")`, not `Section("…")` (the system header measured 3.1:1 on the sheet): 15 Semibold in `FormHeader`'s secondary ink. Single-choice options are `FilterOptionRow` (title, secondary subtitle, action-tint checkmark, `.isSelected`); sliders and toggles are plain `Slider` / `Toggle` rows with an `accessibilityValue`.
- `FilterSheet(detents:)` defaults to medium and large (large only at AX sizes); pass `[.large]` when the options don't fit the medium height (inventory Sort and Filter), since rows cut by the sheet edge fail the clipped-text audit.
- Debug gallery: `FENTON_GALLERY=floating-actions` (journeys in `FloatingActionsJourneyTests`).

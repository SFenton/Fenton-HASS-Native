# Home: iPhone and iPad

> **What:** native Home implementation notes. **Read when:** changing `HassUI/Features/Home`.

- `HomeScreen` is a `ScrollView` in a `NavigationStack` with a large title. HIG: Navigation bars, Scroll views.
- Status rail: `StatusRail` horizontal scroll, chips 44 pt min height. HIG: Buttons (hit targets).
- Sheets: `HomeSheet` enum → `.sheet(item:)`, detents per [modal-sheet](../../patterns/modal-sheet.md).
- Cameras: `CameraGrid` on `DynamicGridLayout`; tiles show the camera's `entity_picture` snapshot (tokenized URL, no auth header needed), refreshed when the entity updates. The viewer (`CameraViewer` → `Features/Cameras/CameraLiveView`) plays live video over that snapshot: WebRTC first through the WebRTC integration's `/api/webrtc/ws` (signed with `auth/sign_path`, go2rtc stream ids `front_door`, `garage_camera`, `upper_deck`, `lower_deck`; same protocol as `SFenton/WebRTC` `www/stream-manager.js`), then core HLS (`camera/stream`) if WebRTC shows no frame within 10 s (HLS gets 25 s: Home Assistant holds the first playlist request 10 to 13 s while a cold stream warms up), then the snapshot with a retry. The snapshot cross-fades out only on the first frame, streams stop in the background and resume on return, and `FENTON_REDACT_PRIVATE` keeps the blurred snapshot over the video with the player at zero opacity (the WebRTC Metal view otherwise draws above the snapshot and leaks the picture into screenshots). The black frame sets the viewer's size and the player and snapshot are clipped overlays, so a fill-scaled snapshot cannot push the Live badge out of frame. Observe `AVPlayer`/`AVPlayerItem` with `observe(_:)` KVO; Combine's `publisher(for:).values` delivered only initial values on iOS 27. Video only for now (no audio). HIG: Playing video (live content shows its state; no scrubbing controls for a live feed).
- Chip sheets: Security opens the Security page's `SecuritySystemSheet`; the other five open the [room overview sheet](../../patterns/room-overview-sheet.md) (room cards, then a pushed room detail with live controls for lights).
- Weather: `WeatherSummaryCard` (`Features/Home/Weather`) is the web `WeatherSummary` card: condition, temperature, the Today rail and a 24-hour carousel, on a dark condition gradient with white text. The header is the card's button ("Open seven-day weather forecast. Rain, 72°F"); the hours are separate elements so VoiceOver reaches each one and scrolling never opens the sheet. The sheet is the card's own `.sheet` (full height, inline "Weather" title with a subtitle on iOS 26, Done), not a `HomeSheet`. Forecasts come from one shared `WeatherForecastStore` (HassCore) that restores its disk snapshot before the first frame. Details, departures and tests: [weather pattern](../../patterns/weather.md). HIG: Scroll views, Page controls, Sheets, Charting data, Accessibility.

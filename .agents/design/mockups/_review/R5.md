## Cross-cutting observations

1. **Literal grid minimums are the one real Dynamic Type bug.** Sprinklers wraps its minimums in `@ScaledMetric`; Chores (150), Solo Trip travelers (140) and `AwaySectionGrid` (340) do not. Three mockups drew the scaled behaviour the kit gives for free, which hid it.
2. **Destructive and irreversible actions are uneven.** Task and grocery delete confirm, Vacation off confirms, but completing a task, ending a Solo Trip and discarding any sheet draft do not; no surface offers undo.
3. **Sheet chrome is consistent and good** (fitted detents, grabber, circle x and check, opaque ground, busy-state locking), but it lacks the HIG unsaved-changes confirmation everywhere.
4. **Busy feedback is inconsistent:** `SheetConfirmItem` swaps to an arc, while `PrimaryButton` sheets (water, schedule, solo trip) only disable.
5. **The shared Chores helper carried author self-checks.** `_chores.js` now lets a mockup's own `reviews` replace the shared block; it also had the AX5 column logic that disagreed with the code.

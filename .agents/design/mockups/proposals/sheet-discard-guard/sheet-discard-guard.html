Discard changes confirmation

Edited drafts vanish on Cancel, Back or swipe-down. A shared dirty-only guard would ask first.

Cause

14 findings. Cancel, Back and swipe-down drop an edited draft with no prompt in every form sheet. Several already compute hasChanges (DonetickTaskSheet, InventoryItemEditor) but only block dismissal while a save runs. HIG Sheets: if changes are unsaved, confirm before dismissing; use an action sheet with a destructive Discard.

Options

On iPad the dialog is a popover anchored to Cancel; on Duo it is the same action sheet.

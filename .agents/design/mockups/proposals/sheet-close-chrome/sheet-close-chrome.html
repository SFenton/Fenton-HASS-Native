Sheet Close role and grabber

Close is a plain dismiss in a confirming toolbar slot, and single-detent sheets show a resize handle. One shared fix in HassModal.

Cause

SheetCloseItem (HassModal.swift) puts the circle-X in .confirmationAction, a role for "Save/Done" that confirms something. Close only dismisses. 14 atlas findings (every sheet that uses it: Climate, Room overview, Weather, Security System, Settings, Presence…). On the iPhone Duo outer display the vertical bar sorts a confirming action as the prominent one, below Back; a close-only sheet (camera, Security System) may also be moved into that bar. Related: hassSheet(.page, height: .full) draws a grabber on a sheet that has only the large detent (sprinkler controller), so the handle suggests a resize that does not exist.

Constraint: owner, 2026-10-13: Close is a circle-X at the top right, like FestivalNativeApps. Moving it to the leading side reverses that, so option B is only here because the role fix needs it.

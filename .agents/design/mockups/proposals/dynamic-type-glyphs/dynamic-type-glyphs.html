Proposal · 2026-10-23

Fixed glyphs, columns and spinners that ignore text size

Literal point sizes beside scaling text leave pictures tiny, or overflowing, at AX5.

Cause

Glyph columns, swatches, spinners and a few numerals use literal point sizes beside text that scales, so at AX5 the picture stays small next to words about 2.7 times larger, or (flame in a 44 pt circle) a scaled glyph outgrows its container. Fix: @ScaledMetric(relativeTo:) the same text style as the neighbouring text, with a ceiling where the container is a fixed circle (FanRailButton precedent: 45%).

Recommendation

Scale all of them as in the table. The one real design call is the arc spinner: the reconnecting arc sits in the header, so the inline arc should be capped (about 1.5× default) to keep the header from growing, which the reconnecting-spinner proposal may change anyway.

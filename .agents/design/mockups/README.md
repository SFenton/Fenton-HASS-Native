# Mockups

> **What:** the proposals the owner reviewed before a visible change was built, one folder per topic. **Read when:** you are about to propose a visible change, or want to see what was weighed for one.

Each folder holds `<topic>/<topic>.html`, a self-contained page, plus any `source/`. The format and the gate are in [workflow/propose-first.md](../../workflow/propose-first.md). A mockup is the record of the options, not the spec: the decision and its rules live in the doc beside this folder.

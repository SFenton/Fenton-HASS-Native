# Fix a reported issue

> **What:** procedure for Report an Issue / Feature Request items. **Read when:** working a tracker item.

1. Reproduce on the platform named in the report.
2. Find the owning pattern or page doc; fix the canonical component, not the instance.
3. Add a regression test, then open a PR that references the item.

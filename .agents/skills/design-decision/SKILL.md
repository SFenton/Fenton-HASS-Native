# Design decision

> **What:** how agents decide a design question the owner hasn't. **Read when:** a choice changes navigation, presentation or a shared pattern.

1. Check the HIG (`apple-hig` skill) and the web behavior.
2. Precedence: owner's explicit choice > HIG > web parity > convenience.
3. Decide, record the rule and its reason in the owning doc, and tell the owner in the thread or PR so they can override.

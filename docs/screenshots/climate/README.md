# Climate screenshots

Gallery fixtures (`FENTON_GALLERY=climate`, `FENTON_GALLERY_CLEAN=1`), no live house data. Named `climate-<view>-<device>.png`.

| View | What |
|---|---|
| `page` | Climate page (home fixture) |
| `page-away` | Climate page while away on vacation, Automatic Thermostat off |
| `hub-picker` | Thermostat Hub mode picker |
| `rooms`, `automation`, `tracking` | Sheet tabs |
| `room` | Living Room detail |
| `predictive` | Predictive Comfort detail |
| `eco-option` | Eco Behavior When Away |
| `tracking-detail` | Selected Rooms |

Devices: `iphone`, `iphone-dark`, `duo-folded`, `duo-unfolded-portrait`, `duo-unfolded-landscape`, `ipad-portrait`, `ipad-landscape`.
